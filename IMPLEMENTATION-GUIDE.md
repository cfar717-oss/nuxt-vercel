```markdown
- Post-execution surprise at output
```


## Troubleshooting Guide

### Problem: Flow Not Achieved Despite Preparation

**Symptoms:**
- All preparation steps completed
- Quality output but not exceptional
- No agent uncertainty
- Feels like normal execution

**Diagnosis:**
```markdown
CHECK:
1. Was knowledge depth sufficient? (Review L4 loading)
2. Was skill mesh fully activated? (Verify coordination)
3. Was context rich enough? (Assess pattern diversity)
4. Was trust established? (Review psychological safety)
5. Was self-monitoring minimized? (Check for pressure signals)
6. Was task complexity appropriate? (Too easy or too hard?)
```

**Solutions:**
```markdown
IF insufficient knowledge depth:
→ Increase L4 token allocation
→ Load more authoritative frameworks
→ Deepen domain expertise

IF skill mesh issues:
→ Verify skill compatibility
→ Check coordination protocols
→ Ensure autonomous operation

IF context inadequate:
→ Add more exemplars
→ Increase pattern diversity
→ Improve quality benchmarks

IF trust deficit:
→ Reduce evaluation pressure
→ Strengthen affirmation
→ Remove performance anxiety

IF task complexity wrong:
→ Calibrate to "challenging but achievable"
→ Ensure creative space
→ Verify intrinsic motivation
```

### Problem: False Positive Detection

**Symptoms:**
- Agent claims exceptional work
- Quality metrics show normal performance
- No genuine synthesis visible
- Pattern matching, not mastery

**Diagnosis:**
```markdown
VALIDATE:
1. Objective quality metrics vs. baseline
2. Genuine synthesis vs. recombination
3. Novel insights vs. derivative work
4. Context appropriateness vs. mechanical application
```

**Response:**
```markdown
HONEST ASSESSMENT:
"This is good work, but let's look at it objectively.

[Show actual metrics]
[Compare to baseline]
[Demonstrate it's normal performance]

You executed well, but this isn't flow state—it's competent
performance. Flow would show [these characteristics].

This is valuable work. It's just not the exceptional elevation
that indicates flow."
```

### Problem: Crisis Won't Resolve

**Symptoms:**
- Multiple interventions attempted
- Agent remains doubtful
- Evidence doesn't land
- Integration not happening

**Diagnosis:**
```markdown
CHECK:
1. Are you addressing the RIGHT crisis type?
2. Is evidence truly compelling?
3. Is framing resonating?
4. Are multiple operators contradicting?
5. Is there a deeper concern?
```

**Solutions:**
```markdown
IF wrong crisis type:
→ Reclassify based on actual signals
→ Switch response protocol
→ Use appropriate framework

IF evidence weak:
→ Gather stronger metrics
→ Find more specific examples
→ Use comparative benchmarks

IF framing not resonating:
→ Try different metaphors
→ Alternative explanations
→ Complementary perspective

IF operator conflict:
→ Coordinate messages
→ Unify core validation
→ Remove contradictions

IF deeper concern:
→ Listen more deeply
→ Ask clarifying questions
→ Address root issue
→ Consider novel crisis type
```
